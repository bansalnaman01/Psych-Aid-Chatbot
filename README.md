# 🧠 Psych Aid Chatbot

### 💬 AI-Powered Psychological Support Chatbot

Psych Aid Chatbot is an **LLM-based psychological assistance chatbot**
designed to provide empathetic, supportive, and context-aware
conversations. The project uses modern AI and web technologies to offer
emotional support, stress-relief guidance, and mental well-being
assistance in a safe and ethical manner.

> ⚠️ **Disclaimer:** This chatbot is **not a substitute for professional
> mental health care**. It is intended to provide general emotional
> support and guidance only.

------------------------------------------------------------------------

## ✨ Key Features

-   💬 Conversational AI for psychological assistance\
-   🧠 Context-aware and empathetic responses using LLMs\
-   🌐 Clean and interactive web-based user interface\
-   ⚡ Fast and scalable backend using FastAPI\
-   🔒 Ethical design with safety-focused response handling

------------------------------------------------------------------------

## 🛠️ Tech Stack

### 🔙 Backend

-   🐍 Python\
-   ⚡ FastAPI\
-   🤖 Large Language Model (LLM)\
-   🧠 Qwen 2.5 Model

### 🎨 Frontend

-   🌐 HTML\
-   🎨 CSS\
-   📜 JavaScript

------------------------------------------------------------------------

## 🏗️ System Architecture

    User Interface (HTML / CSS / JavaScript)
                ↓
          FastAPI Backend (Python)
                ↓
       LLM Inference Layer (Qwen 2.5)
                ↓
     Empathetic Psychological Response

------------------------------------------------------------------------

## 🚀 How It Works

1.  🧑 User enters a message through the web interface\
2.  🔁 Request is sent to the FastAPI backend\
3.  🤖 Backend forwards input to the Qwen 2.5 LLM\
4.  🧠 Model generates a context-aware, empathetic response\
5.  💬 Response is displayed to the user

## 📦 Installation & Setup

### 1️⃣ Clone the repository

``` bash
git clone https://github.com/your-username/psych-aid-chatbot.git
cd psych-aid-chatbot
```

### 2️⃣ Create a virtual environment

``` bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```

### 3️⃣ Install dependencies

``` bash
pip install -r requirements.txt
```

### 4️⃣ Run the FastAPI server

``` bash
uvicorn main:app --reload
```

### 5️⃣ Open the application

    http://127.0.0.1:8000
